.. _arch-scaler:

Scaler
======

.. image:: https://codecov.io/gh/metatensor/metatrain/branch/main/graph/badge.svg?component=scaler
   :target: https://app.codecov.io/gh/metatensor/metatrain/tree/main/src/metatrain/scaler?components%5B0%5D=scaler

*Maintained by* `@pfebrer <https://github.com/pfebrer>`_.

The scaler is a simple model that computes per-target and per-property scaling factors.
It is meant to be used as a preprocessing step for other architectures, so that targets
are standardized before being fed to the main model.

See :ref:`scale-targets` for more details.

.. _arch-scaler_installation:

Installation
------------

To install this architecture along with the ``metatrain`` package, run:

.. code-block:: bash

    pip install metatrain[scaler]

where the square brackets indicate that you want to install the optional
dependencies required for ``scaler``.
