.. _extender-rename:

Rename
======

This extender just passes the inputs to the outputs without any modification.

It is used to rename targets.

For someone who wants to understand how extenders work or wants to implement
their own extender, this is the best point to start, as it is the simplest
extender possible.

It is also very useful for testing and debugging.

.. _extender-rename_installation:

Installation
------------

To install this extender along with the ``metatrain`` package, run:

.. code-block:: bash

    pip install metatrain[extender-rename]

where the square brackets indicate that you want to install the optional
dependencies required for the ``rename`` extender.
